2. Dynamic Reorder Point (ROP) Model

The Sentinel and Forecaster agents compute dynamic ROP based on variable lead times and demand spikes:

$$ROP = (D \times L) + SS$$
$$SS = Z \times \sqrt{L \times \sigma_d^2 + D^2 \times \sigma_L^2}$$
  • • D = Average Hourly/Daily Medicine Consumption Rate
  • • L = Supplier Delivery Lead Time in Hours
  • • SS = Dynamic Safety Stock Buffer
  • • Z = Service Level Factor (99.5% for Life-Saving Drugs)

3. Agentic Economic Order Quantity (EOQ)

The Sourcing Agent balances cold-chain holding cost against urgent replenishment ordering costs:

$$EOQ = \sqrt{\frac{2 \times D \times S}{H \times (1 - \text{Discount}_{\%})}}$$
  • • S = Emergency Order Setup & SLA Courier Fee
  • • H = Refrigerated / Secure Vault Holding Cost
  • • Discount% = Autonomous Volume Discount Tier (5% - 22%)
